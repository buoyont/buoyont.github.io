## 说明

本站由 Hexo 4.2.0 生成的静态文件组成，仓库里只有生成后的静态文件，没有 Hexo 源码。

## 目录结构

- `index.html` — 首页
- `2026/11/20/singapore-major-pickem/` — 文章页（按日期分目录）
- `archives/` — 归档页
- `css/`、`js/`、`fancybox/` — 样式与脚本

## 发文章

新文章按站内 Hexo 模板手写静态页，放在 `年/月/日/文章 slug/` 目录下，同时更新首页和归档页。文章同步自小黑盒。
